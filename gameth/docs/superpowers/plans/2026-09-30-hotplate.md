# HOTPLATE Implementation Plan

> Executed in-session. TDD happens live via `test/engine.test.js` (Node `--test`) for the logic core; presentation layers verified in-browser via `tests.html` and screenshots.

**Goal:** A single-page, dependency-free browser game extending Hotelling's model with seven modifications, three modes, exact Nash detection, and a polished animated UI.

**Architecture:** Seven shipped files under a 12-file cap. Each `src/*.js` uses a UMD wrapper: attaches to `window.HP` in the browser (classic scripts, works over `file://`) and `module.exports` under Node (so the logic core is unit-tested headlessly). Dependency order: core → engine → nash → render → ui.

**Spec:** `docs/superpowers/specs/2026-09-30-hotplate-design.md`

## Global Constraints

- 12 files max in the submission; no build step, no dependencies, no network.
- No ES modules — classic `<script>` tags, single `HP` global.
- All tuned coefficients live in `HP.Engine.CONFIG`. Nothing hard-coded at call sites.
- Recompute after a strategy change < 16 ms (distance-field cache makes this hold).
- Respect `prefers-reduced-motion`. No web fonts. Muted-by-default WebAudio only.

## Cross-file interface contracts (the load-bearing part)

### `HP.Core` (core.js)
```
HP.Core.rng(seed)                      -> { next():float[0,1), int(n), pick(arr) }
HP.Core.generateTown(seed)             -> Town
   Town = { W,H, seed, cells:Float32Array(W*H density base),
            zone:Uint8Array(W*H), graph:Graph, mall:{x,y},
            river:[segments], bridges:[{x,y}], candidates:[idx...] }
HP.Core.ZONES = ['residential','mall','office','campus','park']  // index = zone id
HP.Core.distanceField(town, srcIdx)    -> Float32Array(W*H)  // Dijkstra times, cached
HP.Core.idx(town,x,y) / xy(town,i)     -> index helpers
```

### `HP.Engine` (engine.js) — consumes Core
```
HP.Engine.CONFIG                       -> all coefficients + mods:{demand2d,priceQuality,delivery,roads,agglomRent,loyalty,entry} booleans
HP.Engine.makeState(town)              -> State { players:[Player], round, prevShares:Map, servedAge:Map, entrySeen }
   Player = { id:'A'|'B'|'C', x,y, price, tier:0|1|2, radius, isChain }
HP.Engine.evaluate(town, state)        -> Result {
       perPlayer:[{id,profit,share,revenue,deliveryShare,rent,fixed}],
       territory:Uint8Array(W*H),      // majority holder per cell, 255 = outside/desert
       shareField:Float32Array,        // winner share magnitude for heatmap
       welfare:{ consumerSurplus, avgTravel, underserved:[idx...] },
       marketTotal }
HP.Engine.profitOf(town,state,playerId)-> float   // single-player fast path for sweeps
HP.Engine.stepLoyalty(state,result)    -> void    // fold result into prevShares/servedAge for next round
HP.Engine.checkEntry(town,state,result)-> null | {x,y,region}   // 4.7
```

### `HP.Nash` (nash.js) — consumes Engine
```
HP.Nash.CANDIDATES(town)               -> [{x,y}...]           // pruned candidate locations
HP.Nash.bestResponse(town,state,pid)   -> {x,y,price,tier,gain}  // best deviation for one player
HP.Nash.check(town,state)              -> { stable:bool, deviations:[{pid,gain,x,y,price,tier}] }
HP.Nash.iterate(town,state,maxIters)   -> { outcome:'converged'|'cycling'|'budget', path:[states], cycleAt }
HP.Nash.heatmap(town,state,pid)        -> Float32Array(W*H)    // profit if pid sits at each cell
HP.Nash.aiMove(town,state,pid,persona) -> {x,y,price,tier}     // persona in 'undercutter'|'snob'|'mimic'|'optimizer'
```

### `HP.Render` (render.js) — consumes Core, Engine
```
HP.Render.init(canvases{terrain,demand,territory,entities})
HP.Render.drawTown(town) / drawDemand(town,period)
HP.Render.animateTerritory(prevResult,nextResult, ondone)      // ~600ms morph
HP.Render.drawEntities(town,state, overlays)                   // restaurants, deserts, entry-risk, heatmap
HP.Render.flow(town,state,paths, ondone)                       // customer/scooter animation
HP.Render.capturePNG()                 -> dataURL              // for report figures
HP.Render.setReducedMotion(bool)
```

### `HP.UI` (ui.js) — consumes all
```
HP.UI.boot()   // reads DOM, wires menu -> Campaign/Duel/Lab controllers, starts loop
```

## Build order (each ends in a checkable state)

1. **core.js + test** — RNG determinism, town gen, graph, Dijkstra vs Floyd–Warshall on fixture, one-way asymmetry. `node --test`.
2. **engine.js + test** — CONFIG+mods, logit shares sum to 1 with outside option, profit, welfare monotonicity, loyalty mass-conservation, base-model reproduction (all mods off → centre 50/50), entry fires only when warranted. `node --test`. **This is the correctness gate.**
3. **nash.js + test** — bestResponse finds known deviation on fixture; iterate detects a hand-built cycle and a hand-built fixed point; heatmap argmax matches bestResponse location.
4. **render.js** — 4 layers, DPR-aware, morph, capture. Verified in browser.
5. **style.css + index.html** — visual system, canvas stack, script order.
6. **ui.js** — three modes, verdict banner, welfare strip, controls, city events, seed display, capture button.
7. **tests.html** — runs the same assertions in-browser with visible pass/fail.
8. **README.txt**, then **Analysis_Report.pdf** (figures captured from the running Lab mode, embedded base64).
